# 🎯 btn-hunter — ボタンハンター

「うっかり押し」や「事故タップ」を防ぐための、ボタン誤爆防止セーフティ Chrome 拡張機能。

ページ上の危険なボタンを狙い撃ち（ハント）してロックすると、通常の 1 クリックでは発火しなくなります。
本当に押したいときはダブルクリック → 確認モーダルで承認 → 本来のクリック処理が実行されます。

## 機能

- **🎯 ハンターモード**: 拡張ボタン or `Alt+H` で起動。カーソルがスナイパースコープに変わり、ホバー中のボタンが赤枠でロックオン表示されます
- **🛡️ ハント（ロック）**: 狙ったボタンをクリックするだけでロック。グレーアウト＋🔒バッジ表示になり、シングルクリックは無効化されます
- **⚠️ 二段階解除**: ロック中のボタンをダブルクリックすると確認モーダル（Shadow DOM でページ CSS と隔離）が出現。「今回だけ実行する」でのみ本来の処理が発火します
- **💾 永続化**: ロック情報は `chrome.storage.local` にドメイン単位で保存。リロード後も維持されます
- **🔄 SPA 対応**: `MutationObserver` で後から生成されたボタンにもロックを自動再適用。`document_start` 起動で読み込み直後の素通しウィンドウを最小化しています
- **🚪 モード終了**: `Alt+H` / 右クリック / `Esc` のいずれかでハンターモードを終了できます

## 対応言語（9 言語）

UI はブラウザの表示言語に自動追従します（`chrome.i18n`＋`public/_locales` 方式、デフォルト英語）。

英語 / 中国語（簡体字）/ スペイン語 / ヒンディー語 / アラビア語（RTL 対応）/ ポルトガル語（ブラジル）/ ロシア語 / ベンガル語 / 日本語

言語の追加は `public/_locales/<ロケール>/messages.json` を 1 ファイル足すだけです（キーは英語版に合わせること）。

## 使い方

1. ツールバーの 🎯 ボタンを押す（または `Alt+H`）→ ハンターモード開始（ポップアップは自動で閉じます）
2. スコープカーソルで狙い、ブロックしたいボタンをクリック → ハント完了（グレーアウト＋🔒）
3. ロック中のボタンのシングルクリックは何も起きません（トーストで通知）
4. 本当に押したいときはダブルクリック → 確認モーダル →「今回だけ実行する」
5. ロックを外すときはモーダルの「ハンティング解除」か、ポップアップの一覧から解除

## インストール（開発者モード）

```bash
npm install
npm run build
```

1. `chrome://extensions` を開き、デベロッパーモードを ON
2. 「パッケージ化されていない拡張機能を読み込む」→ `.output/chrome-mv3` を選択

開発中は `npm run dev` で HMR 付きの開発用 Chrome が起動します。

```

```

## 権限の説明（ストア審査向け）

| 権限 / 対象 | 用途 |
| ----------- | ---- |
| `storage` | ロックしたボタンのセレクタを端末内に保存するため |
| `activeTab` | ポップアップ→content script へのメッセージ送信用（クリック時のみ） |
| content scripts `<all_urls>` | 任意の Web ページ上でボタンをハントできるようにするため |

- リモートコード・外部送信は一切ありません（全コードをバンドル）。
- 収集するユーザーデータはありません。ロック情報は端末内の `chrome.storage.local` にのみ保存されます。

### リスティング文案（ドラフト）

- **簡潔な説明（132 文字以内）**: 押し間違い・誤タップを防ぐ！危険なボタンをロックし、ダブルクリック＋確認でのみ実行できるセーフティ拡張。
- **詳細な説明**: btn-hunter（ボタンハンター）は、Web ページ上の「絶対に押し間違えたくないボタン」をロックできる拡張機能です。
  - ワンクリックの事故（誤送信・誤削除・誤購入など）を二段階操作で防止
  - ロックはドメインごとに記憶され、リロード後も維持
  - 確認モーダルでの「今回だけ実行」「ハンティング解除」に対応
  - データの外部送信なし・安心設計
- **カテゴリ**: 生産性
- **言語**: 日本語

### プライバシーポリシー（ドラフト）

> btn-hunter は、ユーザーの個人情報や閲覧データを収集・送信・共有しません。ロックしたボタンの情報は、利用者の端末内のブラウザストレージ（chrome.storage.local）にのみ保存され、外部サーバーへの送信は行いません。

## 既知の制限

- ページ読み込み直後の数十 ms（ストレージ読み込み中）はロック未適用の瞬間があります（`document_start` 起動で最小化済み）
- iframe 内のボタンは対象外（`allFrames` 未設定）
- `chrome://` 配下や Chrome ウェブストアのページでは動作しません（Chrome の仕様）
